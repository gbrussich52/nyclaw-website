## Issues Found

### HIGH — 4 Blog Posts Missing Canonical, OG Tags, and JSON-LD Schemas

The following blog posts are included in `sitemap.ts` but were published before the current
metadata standard was established. They lack `alternates.canonical`, `openGraph`, `twitter`,
`ArticleJsonLd`, and `FAQJsonLd` — all required per the content checklist.

| Post | Route | Words | Missing |
|------|-------|-------|---------|
| Agentic AI Security Best Practices | `/blog/agentic-ai-security-best-practices` | 2,905 | canonical, OG, twitter, ArticleJsonLd, FAQJsonLd |
| What GPT-5.4 Means for AI Assistants | `/blog/gpt-5-4` | 752 | canonical, OG, twitter, ArticleJsonLd, FAQJsonLd |
| How to Build an AI Assistant That Succeeds | `/blog/how-to-succeed` | 1,165 | canonical, OG, twitter, ArticleJsonLd, FAQJsonLd |
| RevenueCat Pulse CLI | `/blog/revenuecat-pulse` | 1,459 | canonical, OG, twitter, ArticleJsonLd, FAQJsonLd |

**Fix**: Upgrade each file to use `type { Metadata }` import, add `alternates.canonical`,
`openGraph { type: 'article' }`, `twitter`, `ArticleJsonLd`, and at minimum a 3-question `FAQJsonLd`.

### HIGH — Thin Content: `/blog/gpt-5-4` (752 words)

Word count is below the 800-word minimum required by the content checklist. This is the
only page flagged for thin content. The topic (GPT-5.4 implications for AI assistants)
is now 6+ months old and references a specific model version — consider either expanding
to 1,200+ words with updated context or redirecting to a more current article.
